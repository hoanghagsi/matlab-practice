# matlab-practice

Repo luyện tập Git và CI/CD.

## Các hàm trong calc.py

- `add(a, b)` — cộng hai số
- `subtract(a, b)` — trừ hai số
- `multiply(a, b)` — nhân hai số
- `divide(a, b)` — chia hai số (có kiểm tra chia cho 0)
- `power(a, b)` — lũy thừa
- `modulo(a, b)` — chia lấy dư
- `square(a)` — bình phương
- `cube(a)` — lập phương
